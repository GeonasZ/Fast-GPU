PROVIDER ACCESS

厂商网页实例接入能力

“可发现”表示厂商 API 能列出网页控制台创建的实例；“接入”还要求平台能够通过 SSH 登录并安装实例专属公钥。

PPIO可直接接入

网页创建的 GPU 实例可通过 API 同步；实例开启 SSH 且详情接口返回地址和密码时，平台可直接校验并接入。若厂商尚未返回 SSH 凭据，可改用私钥、密码或手动安装公钥。

RunPod需要额外 SSH 凭据

网页创建的 Pod 可同步，但平台无法从 API 取得原有 SSH 私钥或密码。需输入可用私钥/密码，或先进入 Pod 手动执行平台提供的公钥安装命令。

Hyperstack需要额外 SSH 凭据

网页创建的 VM 可同步；事后在供应商控制面登记 Keypair 不会自动写入现有 VM。需提供创建时私钥、可用密码，或通过控制台进入 VM 后手动安装平台公钥。

AutoDL普通网页实例暂不能接入

当前接入的是独立的容器实例 Pro API。通过 Pro API 创建的 pro-* 实例可同步，并可使用接口返回的 SSH 密码直接接入；普通网页“我的实例”不在 Pro API 列表中，平台目前无法发现或管理。

无论使用哪种方式，平台都只会在 SSH 校验成功后保存凭据；私钥和密码会加密存储。
